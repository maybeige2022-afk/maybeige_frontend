# MAYBEIGE - 水晶手鍊電商平台

此專案為水晶手鍊電商展示與購買的全端開發網頁，涵蓋從 Figma UI/UX 設計到前後端系統架構的完整實作。主要規劃會員、商品、購物車與訂單處理流程，並設計後台管理功能，支援商品資料維護、庫存狀態更新與訂單管理，具備基本營運流程與系統操作邏輯。**透過專案中對程式語言與介面設計的理解，能更有效地與跨部門團隊進行溝通，協助專案順利推進。**

## 部署與使用須知

- **伺服器啟動延遲**：後端部署於 Render 免費方案。若長時間未有人存取，**首次加載約需等待 30-60 秒** 進行冷啟動，啟動後即可順暢存取。
- **Google 登入限制**：受限於 Google 安全規範，**請勿在嵌入式瀏覽器（如 Line、104 內建瀏覽器）中使用 Google 登入**。若遇到 `403: disallowed_useragent` 錯誤，請點擊右上角並選擇「以 Chrome/Safari 開啟」即可正常登入。

## 開發與部署架構優化 (DevOps Highlight)

本專案實作 **自動化環境切換機制**，確保開發效率與正式環境的穩定性：

- **環境解耦與自動偵測**：利用 Vite 的環境變數機制 (`.env`)，系統會根據執行指令自動切換 API 端點。
  - **開發環境**：自動連接本地localhost，加速開發與除錯。
  - **生產環境**：自動注入 Render 雲端 API 網址，實現無縫部署。
- **CORS 動態安全政策**：後端實作動態來源檢查，確保僅允許受信任的網域進行跨域請求，兼顧開發便利性與線上資產安全。

## 核心功能與實作亮點

### 1. 動態商品管理系統

- **資料驅動渲染**：透過 Axios 串接 MongoDB，根據後端 API 動態產生商品列表。
- **即時過濾搜尋**：開發高效的關鍵字搜尋功能，支援使用者即時選購商品款式。

### 2. 智慧購物車與結帳邏輯

- **狀態同步管理**：在 App.js 管理全域購物車狀態，實作加入、數量增減、刪除商品及總金額自動計算。
- **LocalStorage 持久化**：整合本地儲存機制，確保使用者在重新整理頁面後，購物車資料依然存在。

### 3. 使用者體驗優化

- **全平台響應式**：實作跨斷點 (1200px / 992px / 576px / 400px) 佈局，確保桌機與行動裝置皆有最佳展示效果。
- **行動端互動優化**：設計具備平滑動畫的側邊抽屜式導覽與背景遮罩，大幅提升手持操作便利性。

### 4. 進階商店管理端

這是本專案的核心控制中心，管理者可進行全方位的營運操作：

- **數據導出功能**：實作 **CSV 匯出邏輯**，支援管理者一鍵下載訂單報表，便於進行帳務核對或物流處理。
- **動態狀態管理**：管理者可透過切換按鈕即時更改訂單狀態「處理中、運送中、已完成、已取消」標籤，並同步連動至前端客戶的會員中心。
- **專業權限保護**：嚴格實作後端 Middleware 驗證與前端 Token 檢查，確保訂單敏感資料的安全。

### 5. 進階身分驗證與郵件功能

- **忘記密碼機制**：整合 **Nodemailer** 實作密碼重設流程。系統會自動發送具備 **時效性安全 Token** 的電子郵件，協助使用者安全地重新設定密碼。

## 商業營運擴充規劃

本專案目前處於功能開發展示階段，針對未來正式商轉，已規劃以下技術對接方案：

- **綠界科技 (ECPay) 全方位整合**：
  - **多管道金流**：正式上線後將串接綠界支付閘道，全面支援信用卡、ATM 轉帳及 LINE Pay 等多樣化支付工具。
  - **智慧物流選店**：導入 **7-11 電子地圖** 選擇器，讓消費者能在結帳流程中即時選取方便取貨的門市。
- **自動化營運流程**：透過 API Webhook 機制，在付款成功後自動更新訂單狀態並產出物流編號，實現從下單到寄件的自動化管理。

## 專案技術挑戰與解決方案

### 1. Google OAuth 登入流程與後端同步

- **描述**：在使用者初次登入時，如何確保 Google 授權、後端建立使用者帳號、以及前端 JWT 儲存這三個步驟能順序正確且不報錯。
- **解決方案**：實作了完整的非同步處理邏輯，並在前端開發了登入狀態的 Persistent Check，解決了網頁重新整理後登入失效的問題。

### 2. 高複雜度表格的 UI/UX 與數據對齊優化

- **描述**：後台管理介面需呈現多層級資料（如單筆訂單含多項商品、不同發票類別），導致視覺對齊困難且代碼冗長。
- **解決方案**：
  - **邏輯抽離**：將複雜的發票顯示邏輯封裝於 `renderInvoice` 函數，提升代碼可維護性。
  - **精確對齊技術**：透過 SCSS 的 `vertical-align: middle` 與一致的 `padding` 補償，解決多行文字與單行文字共存時的視覺偏差。

### 3. 跨環境 API 整合與 CORS 障礙

- **描述**：在本地開發與遠端部署間頻繁手動修改 API 網址容易出錯，且會觸發瀏覽器 CORS 攔截。
- **解決方案**：導入 `import.meta.env` 環境變數管理，配合後端 `cors` 套件的動態配置，實現了「代碼不變、環境自動感應」的自動化流程。
