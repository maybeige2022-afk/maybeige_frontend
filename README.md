# MAYBEIGE - 水晶手鍊電商平台

**MAYBEIGE** 是一個韓系風格水晶手鍊的電商平台。本專案採前後端分離架構，前端基於 **React** 構建，並深度還原 **Figma** 的設計規範，體現品牌特有的優雅與簡約。

## 部署與使用須知

- **伺服器啟動延遲**：後端部署於 Render 免費方案。若長時間未有人存取，**首次加載約需等待 30-60 秒** 進行冷啟動，啟動後即可順暢存取。
- **Google 登入限制**：受限於 Google 安全規範，**請勿在嵌入式瀏覽器（如 Line、104 內建瀏覽器）中使用 Google 登入**。若遇到 `403: disallowed_useragent` 錯誤，請點擊右上角並選擇「以 Chrome/Safari 開啟」即可正常登入。

## 技術棧

- **前台架構**：React 18 / React Router 6 / Axios / SCSS
- **後端引擎**：Node.js / Express / MongoDB (Atlas)
- **資安驗證**：Google OAuth 2.0 / JSON Web Token (JWT)
- **設計工具**：Figma

## 核心功能與實作亮點

### 1. 動態商品管理系統

- **資料驅動渲染**：透過 Axios 串接 MongoDB，根據後端 API 動態產生商品列表。
- **即時過濾搜尋**：開發高效的關鍵字搜尋功能，支援使用者即時選購商品款式。

### 2. 智慧購物車與結帳邏輯

- **狀態同步管理**：在 App.js 管理全域購物車狀態，實作加入、數量增減、刪除商品及總金額自動計算。
- **LocalStorage 持久化**：整合本地儲存機制，確保使用者在重新整理頁面後，購物車資料依然存在。

### 3. 使用者體驗優化

- **全平台響應式**：實作跨斷點 (1200px / 992px / 576px / 400px) 佈局，確保桌機與行動裝置皆有最佳展示效果。
- **行動端互動優化**：設計具備平滑動畫的側邊抽屜式導覽 (Side Drawer) 與背景遮罩，大幅提升手持操作便利性。

### 4. 進階商店管理端 (Admin Dashboard)

這是本專案的核心控制中心，管理者可進行全方位的營運操作：

- **數據導出功能**：實作 **CSV 匯出邏輯**，支援管理者一鍵下載訂單報表，便於進行帳務核對或物流處理。
- **動態狀態管理**：管理者可透過非同步請求 (PATCH) 即時切換訂單狀態「處理中、運送中、已完成、已取消」標籤，並同步連動至前端客戶的會員中心。
- **專業權限保護**：嚴格實作後端 Middleware 驗證與前端 Token 檢查，確保訂單敏感資料的安全。

## 專案技術挑戰與解決方案

### 1. Google OAuth 登入流程與後端同步

- **描述**：在使用者初次登入時，如何確保 Google 授權、後端建立使用者帳號、以及前端 JWT 儲存這三個步驟能順序正確且不報錯。
- **解決方案**：實作了完整的非同步處理邏輯，並在前端開發了登入狀態的 Persistent Check，解決了網頁重新整理後登入失效的問題。

### 2. 高複雜度表格的 UI/UX 與數據對齊優化

- **描述**：後台管理介面需呈現多層級資料（如單筆訂單含多項商品、不同發票類別），導致視覺對齊困難且代碼冗長。
- **解決方案**：
  - **邏輯抽離**：將複雜的發票顯示邏輯封裝於 `renderInvoice` 函數，提升代碼可維護性。
  - **精確對齊技術**：透過 SCSS 的 `vertical-align: middle` 與一致的 `padding` 補償，解決多行文字與單行文字共存時的視覺偏差。

### 3. 多層級組件的狀態提升 (Lifting State Up)

- **描述**：由於購物車資訊分散在導覽列、商品頁與側邊購物車中，傳統傳遞方式會導致資料不一致。
- **解決方案**：將核心狀態提升至根組件 `App.js`，透過單向資料流控管所有數據變動，確保全站購物車資訊即時同步。
