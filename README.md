# MAYBEIGE - 水晶手鍊電商平台

MAYBEIGE 是一個韓系風格的水晶手鍊電商網頁。本專案採用前後端分離架構開發，前端使用 React 構建，並嚴格遵循自定義的 Figma 設計規範，確保設計稿與實作成果的高度還原。

## 相關連結

- **線上預覽**: [https://maybeige-frontend.onrender.com/](https://maybeige-frontend.onrender.com/)
- **後台管理 (Demo)**: `/admin-dashboard` (需具備管理員權限)

## 專案使用須知

- **首次加載延遲**：本專案後端部署於 Render 免費方案，若長時間未有人存取，伺服器會進入休眠狀態。**首次開啟網頁約需等待 30-60 秒啟動時間**，啟動後即可恢復流暢體驗。
- **Google 登入限制**：受限於 Google 安全規範，**請勿在嵌入式瀏覽器（如 Line、Messenger 內建瀏覽器）中使用 Google 登入**。若遇到 `403: disallowed_useragent` 錯誤，請點擊右上角並選擇「以 Chrome/Safari 開啟」即可正常登入。

## 技術棧

- **設計工具**：Figma

- **後端開發**：Node.js, Express, MongoDB (Atlas)
- **身分驗證**：Google OAuth 2.0, JWT (JSON Web Token)

## 核心功能實作

### 1. 動態商品管理系統

- **資料驅動渲染**：透過 Axios 串接 MongoDB，根據後端 API 動態產生商品列表。
- **即時過濾搜尋**：開發高效的關鍵字搜尋功能，支援使用者即時選購商品款式。

### 2. 專業商店端管理系統 (Admin Dashboard)

- **訂單全方位追蹤**：管理者可即時查看所有訂單編號、客戶資訊、商品明細與總金額。
- **管理員權限驗證**：後台頁面具備 Token 驗證機制，確保只有持有合法管理員 JWT 的使用者才能存取訂單敏感資料。

### 3. 智慧購物車與結帳邏輯

- **狀態同步管理**：在 App.js 管理全域購物車狀態，實作加入、數量增減、刪除商品及總金額自動計算。
- **LocalStorage 持久化**：整合本地儲存機制，確保使用者在重新整理頁面後，購物車資料依然存在。

### 4. 使用者體驗優化

- **全平台響應式**：實作跨斷點 (1200px / 992px / 576px / 400px) 佈局，確保桌機與行動裝置皆有最佳展示效果。
- **行動端互動優化**：設計具備平滑動畫的側邊抽屜式導覽 (Side Drawer) 與背景遮罩，大幅提升手持操作便利性。

## 專案技術挑戰與解決方案

### 1. Google OAuth 登入流程與後端同步 (核心挑戰)

- **描述**：在使用者初次登入時，如何確保 Google 授權、後端建立使用者帳號、以及前端 JWT 儲存這三個步驟能順序正確且不報錯。
- **解決方案**：實作了完整的非同步處理邏輯，並在前端開發了登入狀態的 Persistent Check，解決了網頁重新整理後登入失效的問題。

### 2. 高複雜度表格的 UI/UX 與數據對齊優化

- **描述**：後台管理介面需呈現多層級資料（如單筆訂單含多項商品、不同發票類別），導致視覺對齊困難且代碼冗長。
- **解決方案**：
  - **邏輯抽離**：將複雜的發票顯示邏輯封裝於 `renderInvoice` 函數，提升代碼可維護性。
  - **精確對齊技術**：透過 SCSS 的 `vertical-align: middle` 與一致的 `padding` 補償，解決多行文字與單行文字共存時的視覺偏差。

### 3. 多層級組件的狀態提升 (Lifting State Up)

- **描述**：由於購物車資訊分散在導覽列、商品頁與側邊購物車中，傳統傳遞方式會導致資料不一致。
- **解決方案**：將核心狀態提升至根組件 `App.js`，透過單向資料流控管所有數據變動，確保全站購物車資訊即時同步。
