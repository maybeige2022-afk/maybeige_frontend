# MAYBEIGE - 水晶手鍊電商平台

MAYBEIGE 是一個韓系風格的水晶手鍊電商網頁。本專案採用前後端分離架構開發，前端使用 React 構建，並嚴格遵循自定義的 Figma 設計規範，確保設計稿與實作成果的高度還原。

## 📢 專案使用須知

- **首次加載延遲**：本專案後端部署於 Render 免費方案，若長時間未有人存取，伺服器會進入休眠狀態。**首次開啟網頁約需等待 30-60 秒啟動時間**，啟動後即可恢復流暢體驗。
- **Google 登入限制**：受限於 Google 安全規範，**請勿在嵌入式瀏覽器（如 Line、Messenger 內建瀏覽器）中使用 Google 登入**。若遇到 `403: disallowed_useragent` 錯誤，請點擊右上角並選擇「以 Chrome/Safari 開啟」即可正常登入。

## UI/UX 設計與品牌理念

- **中性設計美學**：在 Figma 設計階段即規劃簡約的視覺語彙，營造沉穩且具質感的品牌氛圍。
- **組件化開發**：根據 Figma 原型，將商品卡片、購物清單、互動彈窗等拆解為 React 組件，提升代碼複用性與開發效率。
- **全平台響應式**：實作跨斷點 (1200px / 992px / 576px / 400px) 佈局，確保不論在桌機或行動裝置，水晶手鍊的排版展示都能展現。

## 技術棧

- **設計工具**：Figma
- **前端開發**：React 18, React Router 6, Axios, SCSS
- **後端開發**：Node.js, Express, MongoDB (Atlas)
- **身分驗證**：Google OAuth 2.0, JWT (JSON Web Token)

## 核心功能實作

### 1. 動態商品管理系統

- **資料驅動渲染**：透過 Axios 串接 MongoDB，根據後端 API 動態產生商品列表。
- **即時過濾搜尋**：開發高效的關鍵字搜尋功能，支援使用者即時選購商品款式。

### 2. 智慧購物車與結帳邏輯

- **狀態同步管理**：在 App.js 管理全域購物車狀態，實作加入、數量增減、刪除商品及總金額自動計算。
- **LocalStorage 持久化**：整合本地儲存機制，確保使用者在瀏覽過程中重新整理頁面，購物車資料依然存在。

### 3. 使用者體驗與細節微調

- **行動端互動體驗優化**：針對行動裝置設計「直覺式操作」流程，包含具備平滑動畫的側邊抽屜式導覽（Side Drawer）與背景遮罩，並手動微調小螢幕下的觸控熱區，大幅提升單手操作的便利性。

## 專案技術挑戰與解決方案

### 1. Google OAuth 登入流程與後端同步 (核心挑戰)

- **描述**：在串接 Google 第三方登入時，遇到前端 Token 取得與後端資料庫驗證的同步問題。特別是在使用者初次登入時，如何確保 Google 授權、後端建立使用者帳號、以及前端狀態更新（JWT 儲存）這三個非同步步驟能順序正確且不報錯。
- **解決方案**：
  - 實作了完整的非同步處理邏輯，確保前端在收到 Google Response 後，立即發送 API 請求至後端驗證。
  - 使用 JWT 處理後續的身份維持，並在前端實作了登入狀態的 Persistent Check，解決了網頁重新整理後登入失效的問題。

### 2. 多層級組件的狀態提升 (Lifting State Up)

- **描述**：由於購物車資訊分散在導覽列、商品頁面與側邊購物車中，傳統的 Props 傳遞會導致資料不一致。
- **解決方案**：將核心狀態提升至根組件 App.js，並透過單向資料流控管所有數據變動，確保全站購物車數量與金額即時同步。

### 3. 行動裝置 RWD 的細節適配

- **描述**：在 576px 以下的極小螢幕，導覽列空間受限，傳統設計容易導致圖示重疊。
- **解決方案**：利用 SCSS 變數與數學偏移量（transform: translate），將數字精準「嵌入」圖示，並針對不同圖示（User, Bag, Bars）進行視覺權重微調，達成視覺平衡。
